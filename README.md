# LCA-cosmetic-packaging
## Simplified LCA of a cosmetic foundation
**Product**: Estée Lauder Double Wear Sheer Long-Wear SPF 20 (30ml)

**Author**: Silvia Camagna
## Project overview 
A simplified Life Cycle Assessment (LCA) of a commercial liquid foundation, analysing environmental impact across six life cycle stages and proposing a sustainable redesign.
